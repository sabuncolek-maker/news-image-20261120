One image that sums up the world news of **Friday, 20 November 2026**, laid
out as a bold newspaper front page ("THE WORLD TODAY") with the date printed
in the masthead. The six stories, each reported on 20 November 2026:

- **Politics** — Trump, Xi & Putin hold their first-ever three-way summit at
  APEC in China and release a joint "peace declaration" (BBC).
- **World Court** — The ICJ rules Myanmar's military committed genocide
  against the Rohingya (ICJ reports).
- **Climate** — Cyclone Akvan drives 300,000 people to evacuate as it hits
  India's east coast (The Hindu).
- **Tech & Business** — Anthropic shares soar 17% on their first day of
  trading (The Hindu).
- **Space** — NASA confirms Voyager 1 is now one light-day from Earth; a
  signal takes 24 hours to reach it (NASA reports).
- **Arts** — A Van Gogh painting sells for a record $190.4 million.

The image (`entry.png`, 1024×1024) is drawn programmatically with simple,
high-contrast icons and large type so every headline stays readable.

## Run it

```sh
python3 main.py
```

`main.py` (pure Python standard library, no network) copies the bundled
`entry.png` to `/output/entry.png`, creating the folder if needed. Running
it any number of times produces the identical file.
